## 🌟 Overview

This directory contains the complete, standalone **Web-Based Application & Progressive Web App (PWA)** for **SSS: Smart Safety Shield (v.56964.1)**.

### Features:
1. **🔴 1-Tap SOS Emergency Beacon**: Instant zero-latency trigger with 5-second graceful vibration cancel window.
2. **🔊 Acoustic Siren Synthesizer**: Web Audio API frequency sweep (800Hz–1600Hz) overriding DND/Silent mode.
3. **🫀 110 BPM Visual & Spoken CPR Metronome**: AHA/ERC compliant chest compression rhythm guide with 30+ language voiceover.
4. **⚡ 8-Second Animated CPR Micro-Tutorial**: High-contrast visual vector guide for helpers and delivery riders.
5. **🛵 10-Minute SSS Street Fleet Radar**: Simulated and API-ready delivery responder map (Zepto, Blinkit, Swiggy, Uber).
6. **🫀 Live ECG & Cardiac Vitals**: Animated P-QRS-T electrocardiogram canvas and medication reminders.
7. **🚲 BLE 5.0 Handlebar Clicker Support**: Wireless blind-trigger simulation for motorcyclists and vehicle drivers.
8. **🎁 Bank Offers & 30-Day Pro Free Trial**: Built-in promo coupon engine (HDFC50, ICICI40, CRED300, STARFREE).
9. **📶 100% Offline Service Worker (`sw.js`)**: Caches all audio, scripts, and UI for 0ms offline boot.

## 🚀 How to Run

- **Direct in Browser**: Double-click `index.html` or `run_app.bat`.
- **Install to Phone**: Use the root `host_on_phone.bat` server over Wi-Fi.
